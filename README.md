# EliGPT

## Αποθετήριο διπλωματικής εργασίας

**Συγγραφέας:** Νίντσιος Συμεών  
**Αριθμός Μητρώου:** 1997

Το αποθετήριο περιλαμβάνει τον κώδικα και συνοδευτικό υλικό της διπλωματικής εργασίας για το **EliGPT**, ένα πρωτότυπο περιβάλλον προσομοιωμένων συνεντεύξεων με συνθετικές περσόνες ογκολογικών ασθενών.

Ο χρήστης αναλαμβάνει τον ρόλο του ερευνητή και συνομιλεί με μια περσόνα της οποίας οι απαντήσεις παράγονται από μεγάλο γλωσσικό μοντέλο. Η εφαρμογή προορίζεται για διερεύνηση της χρήσης τέτοιων προσομοιώσεων στην εξάσκηση συνεντεύξεων έρευνας εμπειρίας χρήστη (UX).

## Περιεχόμενα

| Αρχείο ή φάκελος | Περιεχόμενο |
| --- | --- |
| `README.md` | Περιγραφή του έργου και οδηγίες χρήσης. |
| `licence` | Όροι άδειας χρήσης του αποθετηρίου. |
| `Online_EliGPT/` | Διαδικτυακή έκδοση με frontend και backend που επικοινωνεί με εξωτερικές υπηρεσίες γλωσσικών μοντέλων. |
| `Local_EliGPT/` | Τοπική έκδοση με frontend, FastAPI backend και σύνδεση με το LM Studio. |

| `Extra/` | Αρχεία εκπαίδευσης Meltemi. |

## Βασικές λειτουργίες

- Δημιουργία περσόνας μέσω επιλογής χαρακτηριστικών ή ελεύθερης περιγραφής στη λειτουργία **Custom**.
- Διεξαγωγή συνέντευξης στα ελληνικά ή στα αγγλικά.
- Χρήση χαρακτηριστικών περσόνας, οδηγιών ρόλου και πρόσφατου ιστορικού για την παραγωγή απαντήσεων.
- Κανόνες μεταβολής δείκτη διάθεσης και επικοινωνιακής στάσης κατά τη συζήτηση.
- Επιλογή διάρκειας συνέντευξης.
- Αποθήκευση και προβολή συνομιλιών σε μορφή JSON.
- Συνοπτικά στατιστικά από τις αποθηκευμένες συνεδρίες.

Ο δείκτης διάθεσης είναι μεταβλητή της προσομοίωσης. Δεν αποτελεί μέτρηση πραγματικού συναισθήματος ή ενσυναίσθησης.

## Οι δύο εκδόσεις

| Χαρακτηριστικό | Διαδικτυακή έκδοση | Τοπική έκδοση |
| --- | --- | --- |
| Διεπαφή | HTML, CSS και JavaScript | HTML, CSS και JavaScript |
| Backend | Python και FastAPI | Python και FastAPI |
| Παραγωγή απαντήσεων | Κύρια κλήση μέσω Google API και εναλλακτική διαδρομή μέσω OpenRouter | Ένα μοντέλο μέσω του τοπικού server του LM Studio |
| Fallback | Αλυσίδα εναλλακτικών μοντέλων στον backend | Δεν χρησιμοποιείται |
| Ρυθμίσεις μοντέλου | Μέσω κώδικα και μεταβλητών περιβάλλοντος | LM Studio και ρυθμίσεις του τοπικού backend |
| Αποθήκευση | JSON στο περιβάλλον εκτέλεσης του backend | JSON στον τοπικό υπολογιστή |
| Αποστολή email | Προαιρετικά μέσω Resend | Δεν περιλαμβάνεται |

Η διαδικτυακή έκδοση έχει σχεδιαστεί για διάθεση του frontend στο Vercel και του backend στο Render. Η τοπική έκδοση εκτελείται στον υπολογιστή του χρήστη. Η παραγωγή απαντήσεων σε αυτήν δεν απαιτεί Google API ή OpenRouter.

## Εκτέλεση της τοπικής έκδοσης

Απαιτούνται **Python 3.10 ή νεότερη**, **LM Studio** και ένα μοντέλο συνομιλίας που μπορεί να εκτελεστεί στο διαθέσιμο υλικό.

1. Άνοιξε το LM Studio, φόρτωσε το μοντέλο και ενεργοποίησε τον τοπικό server στη θύρα `1234`.
2. Χρησιμοποίησε το system prompt της τοπικής υλοποίησης στο LM Studio και διατήρησε το **Thinking απενεργοποιημένο**. Ο backend στέλνει επίσης δυναμικές οδηγίες με το προφίλ και τον ρόλο της περσόνας. Οι οδηγίες των δύο σημείων πρέπει να συμφωνούν.
3. Άνοιξε τερματικό στον φάκελο `Local_EliGPT` και εγκατέστησε τις εξαρτήσεις:

```sh
python -m pip install -r requirements.txt
```

Συνιστάται η εγκατάσταση σε ξεχωριστό Python virtual environment.

4. Όρισε το `LM_MODEL` με το **ακριβές αναγνωριστικό** που εμφανίζει το LM Studio. Για παράδειγμα, σε PowerShell:

```powershell
$env:LM_MODEL = "το-αναγνωριστικό-του-μοντέλου"
python server_gemma26.py
```

Σε macOS/Linux:

```sh
export LM_MODEL='το-αναγνωριστικό-του-μοντέλου'
python server_gemma26.py
```

Η διορθωμένη τοπική έκδοση μπορεί να επιλέξει αυτόματα μοντέλο μόνο όταν το endpoint `/v1/models` επιστρέφει ακριβώς ένα υποψήφιο μοντέλο συνομιλίας.

5. Άνοιξε το **http://127.0.0.1:8000** στον browser. Το `index.html` σερβίρεται από τον backend και δεν χρειάζεται άνοιγμα με διπλό κλικ.

Τα `index.html` και `server_gemma26.py` πρέπει να βρίσκονται στον ίδιο φάκελο. Τα προαιρετικά `logo.png`, `avatars/` και `backgrounds/` τοποθετούνται επίσης εκεί. Αναλυτικότερες οδηγίες και διαθέσιμες ρυθμίσεις περιλαμβάνονται στο [README της τοπικής έκδοσης](Local_EliGPT/README_GR.md).

## Ρύθμιση της διαδικτυακής έκδοσης

Ο φάκελος `online_EliGPT` περιλαμβάνει τη διεπαφή και τον κώδικα του διαδικτυακού backend. Οι βασικές Python εξαρτήσεις είναι `fastapi`, `uvicorn`, `httpx` και `pydantic`.

Οι βασικές μεταβλητές περιβάλλοντος είναι:

| Μεταβλητή | Χρήση |
| --- | --- |
| `GOOGLE_API_KEY` | Πρόσβαση στον κύριο πάροχο παραγωγής απαντήσεων. |
| `GOOGLE_GEMMA_MODEL` | Αναγνωριστικό μοντέλου για την κύρια διαδρομή. |
| `OPENROUTER_API_KEY` | Πρόσβαση στην εναλλακτική διαδρομή παραγωγής. |
| `LM_MODEL` | Ρύθμιση μοντέλου OpenRouter, σύμφωνα με την αλυσίδα του backend. |
| `ALLOWED_ORIGINS` | Επιτρεπόμενες διευθύνσεις frontend για CORS. |
| `PUBLIC_APP_URL` | Διεύθυνση της εφαρμογής που δηλώνεται στις κλήσεις OpenRouter. |
| `RESEND_API_KEY`, `RESEND_FROM`, `NOTIFY_EMAIL` | Προαιρετική αποστολή αποθηκευμένων συνεντεύξεων μέσω email. |
| `PORT` | Θύρα εκτέλεσης του backend. |

Στο frontend, η σταθερά `API` πρέπει να δείχνει στη διεύθυνση του δικού σου backend. Στο περιβάλλον φιλοξενίας του backend μπορεί να χρησιμοποιηθεί η εντολή:

```sh
python server_gemma26.py
```

Τα κλειδιά API ορίζονται στο περιβάλλον εκτέλεσης και δεν καταχωρίζονται στον πηγαίο κώδικα. Η διαθεσιμότητα των μοντέλων και οι όροι των παρόχων μπορεί να διαφέρουν από την περίοδο εκπόνησης της εργασίας.

## Αρχεία συνομιλιών

Ο φάκελος `sunomilies` προορίζεται για τα επιλεγμένα JSON που συνοδεύουν τη διπλωματική. Είναι διαφορετικός από τον φάκελο `sessions` που χρησιμοποιεί κάθε εφαρμογή κατά την εκτέλεσή της.

Ανάλογα με την έκδοση, ένα αρχείο συνεδρίας περιλαμβάνει το προφίλ της περσόνας, τη γλώσσα, τους χρόνους δημιουργίας και αποθήκευσης και το ιστορικό μηνυμάτων. Στο ιστορικό, το πεδίο `role` διακρίνει τις ερωτήσεις του χρήστη (`user`) από τις αποκρίσεις της περσόνας (`assistant`). Πρόσθετα πεδία μπορεί να καταγράφουν το Custom προφίλ ή στοιχεία της εκτέλεσης.

Οι απαντήσεις της περσόνας είναι συνθετικές και δεν αποτελούν μαρτυρίες πραγματικών ασθενών. Πριν από τη δημόσια ανάρτηση συνομιλιών, χρειάζεται έλεγχος και των ερωτήσεων που πληκτρολόγησε ο χρήστης, ώστε να μην περιλαμβάνουν προσωπικά στοιχεία τρίτων.

## Αξιολόγηση και περιορισμοί

Η εργασία εξετάζει την τεχνική υλοποίηση του πρωτοτύπου, τους μηχανισμούς ελέγχου και τη διαμορφωτική ανατροφοδότηση UX. Η επιτυχία ελέγχων στον κώδικα δεν αποτελεί μέτρηση της ακρίβειας του γλωσσικού μοντέλου, της μακροχρόνιας συνέπειας της περσόνας ή της εκπαιδευτικής αποτελεσματικότητας της εφαρμογής.

Το EliGPT δεν προορίζεται για διάγνωση, θεραπευτικές οδηγίες ή υποκατάσταση έρευνας με πραγματικούς συμμετέχοντες. Η φυσικότητα των απαντήσεων δεν εξασφαλίζει ότι αναπαριστούν με ακρίβεια τις εμπειρίες ογκολογικών ασθενών.

Οι ενεργές συνεδρίες διατηρούνται στη μνήμη του backend. Μετά την επανεκκίνησή του, τα αποθηκευμένα JSON μπορούν να προβληθούν εφόσον διατηρείται ο χώρος αποθήκευσης, αλλά η ενεργή συνεδρία δεν επανέρχεται αυτόματα. Στη διαδικτυακή διάθεση απαιτείται κατάλληλη μόνιμη αποθήκευση για διατήρηση αρχείων πέρα από τον κύκλο ζωής του περιβάλλοντος φιλοξενίας.
