# EliGPT — Onco-Persona Interviewer

**Live:** [eli-gpt-chatbot.vercel.app](https://eli-gpt-chatbot.vercel.app/)

Ένα εργαλείο εξομοίωσης συνέντευξης με ογκολογικό ασθενή. Ένα LLM υποδύεται μια τυχαία (ή προσαρμοσμένη) persona ασθενή — με όνομα, ηλικία, διάγνωση, χαρακτήρα και προσωπική ιστορία — και ο χρήστης κάνει τον ρόλο του ερευνητή/συνεντευκτή. Φτιάχτηκε για εκπαίδευση σε ποιοτική έρευνα / κλινικές συνεντεύξεις σε ασφαλές, προσομοιωμένο περιβάλλον.

---

## Πώς λειτουργεί

- Κάθε συνέντευξη ξεκινά με μια **persona ασθενή** — τυχαία ή επιλεγμένη από το χρήστη (όνομα, ηλικία, διάγνωση, στάδιο, χαρακτήρας, οικογενειακή κατάσταση, επάγγελμα, φάση θεραπείας κ.λπ.), ή εντελώς **ελεύθερη περιγραφή** (καρτέλα *Custom*).
- Ο ασθενής απαντά μέσω LLM, με system prompt που περιλαμβάνει τον χαρακτήρα του, «βιώματα» καθημερινότητας/θεραπείας/οικογένειας, και κανόνες ομιλίας (πρώτο πρόσωπο, σύντομες προτάσεις, όχι ιατρική ορολογία που δεν θα ήξερε).
- Υπάρχει **δυναμική διάθεση (mood)**: αν ο χρήστης δείχνει ενσυναίσθηση ο ασθενής ανοίγεται σταδιακά· αν είναι υπερβολικά κλινικός/ψυχρός κλείνεται· αν είναι προσβλητικός η διάθεση πέφτει απότομα και, στο κατώφλι, ο ασθενής **τερματίζει μόνος του τη συνέντευξη** (walkout).
- Off-topic ερωτήσεις (μαθηματικά, πολιτική, προγραμματισμός κ.λπ.) απορρίπτονται ευγενικά — ο ασθενής μένει μέσα στον ρόλο του.
- Η συνέντευξη έχει χρονόμετρο, αποθηκεύεται ως JSON, και υπάρχουν συγκεντρωτικά στατιστικά (πλήθος συνεντεύξεων, μέσος όρος ερωτήσεων, συχνότερες διαγνώσεις).
- Διαθέσιμο σε **Ελληνικά** και **Αγγλικά** (επιλογή γλώσσας στην αρχή).

## Στοίβα

| Επίπεδο  | Τεχνολογία |
|----------|------------|
| Frontend | Καθαρό HTML/CSS/JS (χωρίς build step), hosted στο **Vercel** |
| Backend  | **FastAPI** (Python), hosted στο **Render** |
| LLM      | Gemma 4 26B μέσω **Google Gemini API** (πρωτεύον) → fallback chain μέσω **OpenRouter** (Llama 3.3 70B → GPT-OSS 20B → Nemotron) |
| Email    | Προαιρετική αποστολή αποθηκευμένων συνεντεύξεων μέσω **Resend** (το Render's free tier μπλοκάρει SMTP) |

Backend και frontend είναι δύο ξεχωριστές υπηρεσίες — το frontend μιλάει στο backend αποκλειστικά μέσω HTTP (`fetch`) στα endpoints παρακάτω.

## Δομή project

```
.
├── index.html               # Frontend — ολόκληρο το UI σε ένα αρχείο (deploy: Vercel)
├── server_gemma26.py        # Backend — FastAPI app (deploy: Render)
├── avatars/                # SVG avatars ασθενών (male/female × young/middle/elder)
├── backgrounds/            # Εικόνες φόντου συνομιλίας (προαιρετικές, επιλέγονται στο setup)
├── sessions/                # Αποθηκευμένες συνεντεύξεις σε JSON (δημιουργείται αυτόματα)
└── logo.png                 # Favicon / λογότυπο sidebar
```

> ⚠️ Ο φάκελος `sessions/` είναι στο **ephemeral filesystem** του Render — διαγράφεται σε κάθε redeploy. Γι' αυτό υπάρχει η προαιρετική αποστολή email μέσω Resend, ως αντίγραφο ασφαλείας.

## Εγκατάσταση & τοπική εκτέλεση

### Backend

```bash
pip install fastapi uvicorn httpx pydantic
python server_gemma26.py
```

Χρειάζεται τα εξής **environment variables** (όλα προαιρετικά — χωρίς αυτά το backend τρέχει αλλά ο αντίστοιχος μηχανισμός απενεργοποιείται):

| Μεταβλητή | Σκοπός |
|---|---|
| `GOOGLE_API_KEY` | Direct κλήση στο Gemma 4 μέσω Google Gemini API (πρωτεύον μοντέλο) |
| `GOOGLE_GEMMA_MODEL` | Όνομα μοντέλου Gemini (default: `gemma-4-26b-a4b-it`) |
| `OPENROUTER_API_KEY` | Fallback chain όταν αποτύχει το direct Gemma |
| `LM_MODEL` | Override του πρώτου fallback μοντέλου στο OpenRouter |
| `RESEND_API_KEY` | Αποστολή αποθηκευμένων συνεντεύξεων με email |
| `RESEND_FROM` | Sender address στο Resend (default: `onboarding@resend.dev`) |
| `NOTIFY_EMAIL` | Παραλήπτης των emails με τις συνεντεύξεις |
| `PUBLIC_APP_URL` | Χρησιμοποιείται μόνο ως `HTTP-Referer` header στο OpenRouter |
| `PORT` | Port του server (Render το ορίζει αυτόματα) |

### Frontend

Το `index.html` είναι στατικό — απλά άνοιξέ το ή κάνε deploy σε οποιοδήποτε static host (Vercel, Netlify κ.λπ.). Η μόνη σύνδεση με το backend είναι η σταθερά στην κορυφή του `<script>`:

```js
const API = "https://eligpt.onrender.com";
```

Άλλαξέ το σε `http://127.0.0.1:8000` για τοπικό testing με τοπικό backend.

## API Endpoints

| Method & Path | Περιγραφή |
|---|---|
| `POST /start` | Ξεκινά νέα session — δέχεται επιλογές persona (ή custom περιγραφή) + γλώσσα, επιστρέφει το πρώτο μήνυμα του ασθενή |
| `POST /chat` | Στέλνει μήνυμα χρήστη, επιστρέφει απάντηση ασθενή + τρέχον mood score (+ `ended: true` αν ο ασθενής μόλις τερμάτισε τη συνέντευξη) |
| `POST /save` | Αποθηκεύει τη συνέντευξη σε JSON (+ προαιρετικό email) |
| `GET /sessions` | Λίστα αποθηκευμένων συνεντεύξεων |
| `GET /sessions/{filename}` | Πλήρες περιεχόμενο μιας αποθηκευμένης συνέντευξης |
| `DELETE /sessions/{filename}` | Διαγραφή αποθηκευμένης συνέντευξης |
| `GET /backgrounds` | Λίστα διαθέσιμων εικόνων φόντου |
| `GET /models` | Λίστα διαθέσιμων μοντέλων στο OpenRouter |
| `GET /stats` | Συγκεντρωτικά στατιστικά (σύνολο συνεντεύξεων, μέσος όρος ερωτήσεων, συχνότερες διαγνώσεις) |

## Σημειώσεις / γνωστοί περιορισμοί

- Το LLM μπορεί περιστασιακά να παράγει «κατεστραμμένο» ή επαναλαμβανόμενο κείμενο (γνωστό artifact των free-tier μοντέλων) — υπάρχει ανίχνευση (`_looks_corrupted`) που προκαλεί αυτόματο fallback στο επόμενο μοντέλο της αλυσίδας.
- Οι συνεδρίες κρατούνται **in-memory** στο backend (`sessions: dict`) — επανεκκίνηση του server σβήνει τις ενεργές (όχι τις ήδη αποθηκευμένες) συνεδρίες.
- Δεν υπάρχει authentication — το εργαλείο προορίζεται για ελεγχόμενη, εσωτερική χρήση.

## Άδεια / σκοπός

Εκπαιδευτικό/ερευνητικό εργαλείο προσομοίωσης. Δεν αντικαθιστά πραγματικές συνεντεύξεις με ασθενείς ούτε παρέχει ιατρικές συμβουλές — ο «ασθενής» είναι ρητά προγραμματισμένος να παραπέμπει σε γιατρό για οτιδήποτε κλινικό.
