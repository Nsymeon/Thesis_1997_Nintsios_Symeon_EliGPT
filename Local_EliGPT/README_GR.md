# EliGPT Τοπική εφαρμογή με LM Studio

## Εκκίνηση

Απαιτείται Python 3.10 ή νεότερη και το LM Studio. Τα `index.html` και `server_gemma26.py` πρέπει να βρίσκονται στον ίδιο φάκελο.

1. Άνοιξε το LM Studio, φόρτωσε ένα μοντέλο συνομιλίας και ξεκίνησε τον local server στη θύρα 1234, από την καρτέλα Developer. Απενεργοποίησε το Thinking για αυτή τη ροή σύντομων απαντήσεων.
2. Άνοιξε τερματικό στον φάκελο της εφαρμογής και εγκατέστησε τις εξαρτήσεις:

```sh
python -m venv .venv
```

Σε Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:LM_MODEL = "ΤΟ ΑΚΡΙΒΕΣ MODEL IDENTIFIER ΑΠΟ ΤΟ LM STUDIO"
.\.venv\Scripts\python.exe server_gemma26.py
```

Σε macOS/Linux:

```sh
.venv/bin/python -m pip install -r requirements.txt
export LM_MODEL='ΤΟ ΑΚΡΙΒΕΣ MODEL IDENTIFIER ΑΠΟ ΤΟ LM STUDIO'
.venv/bin/python server_gemma26.py
```

Αν το `/v1/models` επιστρέφει ακριβώς ένα μοντέλο συνομιλίας, μπορείς να παραλείψεις τη ρύθμιση LM_MODEL. Αν υπάρχουν περισσότερα, όρισέ την ρητά. Δεν είναι ασφαλές να μαντέψουμε το αναγνωριστικό από το εμπορικό όνομα του μοντέλου.

3. Άνοιξε στον browser: http://127.0.0.1:8000 . Μην ανοίγεις το HTML με διπλό κλικ.
4. Δημιούργησε περσόνα, κλείσε το παράθυρο οδηγιών και στείλε μια ερώτηση. Δοκίμασε ελληνική και αγγλική συνέντευξη, καθώς και αποθήκευση/ανάκτηση.

Τα προαιρετικά `logo.png`, `avatars/` και `backgrounds/` δεν περιλαμβάνονταν στα δύο συνημμένα. Αντέγραψέ τα από την υπάρχουσα εφαρμογή στον ίδιο φάκελο. Χωρίς αυτά η εφαρμογή λειτουργεί χωρίς τις αντίστοιχες εικόνες. Κράτησε επίσης αντίγραφο του παλιού φακέλου `sessions/` και μετέφερε τα JSON στον νέο φάκελο `sessions/` αν θέλεις να διατηρήσεις τις συνεντεύξεις.

## Ρυθμίσεις

- `LM_MODEL`: ακριβές αναγνωριστικό από LM Studio.
- `LM_BASE_URL`: προεπιλογή `http://127.0.0.1:1234/v1`.
- `LM_TIMEOUT`: χρόνος αναμονής σε δευτερόλεπτα, προεπιλογή 180.
- `LM_API_TOKEN`: προαιρετικό token, αν έχεις ενεργοποιήσει authentication στο LM Studio.
- `ELIGPT_SESSIONS_DIR`: προαιρετική διαφορετική διαδρομή αποθήκευσης.

Οι μεταβλητές ορίζονται στο τερματικό πριν από την εκκίνηση. Δεν χρειάζεται Google API ή OpenRouter για την παραγωγή απαντήσεων. Η συμβατή διεπαφή LM Studio τεκμηριώνεται στο https://lmstudio.ai/docs/developer/openai-compat .

## Διορθώσεις

- Χρήση της τελικής απάντησης `content`, χωρίς παρουσίαση του `reasoning_content` ως λόγου ασθενούς. Κενή τελική απόκριση επιστρέφει σαφές σφάλμα.
- Ρυθμιζόμενο model identifier και χειρισμός timeout, διακοπής σύνδεσης και μη έγκυρης απόκρισης.
- Το πλήρες προφίλ, περιλαμβανομένων επαγγέλματος, οικογενειακής κατάστασης, κατοικίας, εκπαίδευσης και θεραπευτικής φάσης, αποστέλλεται στο prompt.
- Ενσωμάτωση του βασικού deterministic Custom parser της προηγούμενης διαδικτυακής έκδοσης. Αναγνωρίζει επιλεγμένες ρητές διατυπώσεις· δεν κατανοεί κάθε πιθανή φυσική περιγραφή. Τα μη αναγνωρισμένα πεδία παραμένουν τυχαία και το πλήρες Custom κείμενο αποστέλλεται επίσης στο μοντέλο.
- Η διάθεση και το ιστορικό ενημερώνονται μόνο όταν ολοκληρωθεί επιτυχώς ο διαλογικός γύρος. Τα αιτήματα της ίδιας συνεδρίας εκτελούνται διαδοχικά.
- Τερματισμένη από αποχώρηση ασθενούς συνεδρία δεν μεταβάλλεται από επόμενα μηνύματα.
- Έλεγχος HTTP αποτυχιών στο frontend και προβολή σφαλμάτων σύνδεσης.
- Προστασία από διπλή αποστολή. Η λήξη χρόνου και η αποθήκευση περιμένουν την εκκρεμή απάντηση. Το κείμενο που δεν έχει αποσταλεί όταν λήξει ο χρόνος δεν αποστέλλεται αυτόματα.
- Επαναλαμβανόμενη αποθήκευση της ίδιας συνεδρίας ενημερώνει το ίδιο JSON, με προσωρινό αρχείο και αντικατάσταση. Οι διαδρομές βασίζονται στον φάκελο του server.
- Αποθήκευση Custom περιγραφής, αναγνωρισμένων πεδίων, επιλεγμένης διάρκειας, φόντου, διάθεσης και κατάστασης αποχώρησης.
- Έλεγχος ονομάτων αρχείων στα endpoints ανάκτησης/διαγραφής.
- Ο FastAPI σερβίρει τη σελίδα και τους προαιρετικούς φακέλους εικόνων χωρίς δεύτερο web server.

## Τι επαληθεύτηκε

Πέρασαν 11 αυτοματοποιημένα backend tests με προσομοιωμένες αποκρίσεις LM Studio: εξυπηρέτηση σελίδας, επικύρωση εισόδου, Custom προφίλ, τελική απάντηση αντί reasoning, συμπερίληψη στοιχείων στο prompt, επαναφορά κατάστασης σε αποτυχία, χειρισμός κενής απόκρισης, τερματισμένη συνεδρία, αποθήκευση/ανάκτηση/στατιστικά/διαγραφή, προστασία διαδρομών, offline/timeout και επιλογή μοντέλου.

Έγινε έλεγχος σύνταξης Python και JavaScript. Δοκιμάστηκαν επίσης σε JavaScript η διπλή αποστολή, η λήξη χρόνου με εκκρεμή απάντηση, η αποχώρηση ασθενούς και η σειρά απάντησης/αποθήκευσης.

Δεν έγινε πραγματική παραγωγή με το εγκατεστημένο μοντέλο σου ούτε πλήρης οπτική δοκιμή σε browser. Οι παραπάνω έλεγχοι επιβεβαιώνουν τη λειτουργική διασύνδεση με προσομοιωμένη υπηρεσία, όχι την ποιότητα ή την ταχύτητα του μοντέλου στον υπολογιστή σου.

Για επανάληψη των backend tests:

```sh
python test_local.py
```

## Διαφορές από τη διαδικτυακή εφαρμογή

Η έκδοση αυτή καλύπτει τη βασική τοπική ροή: περσόνες, Custom, ελληνικά/αγγλικά, συνέντευξη, διάθεση, αποθήκευση, ανάκτηση και στατιστικά. Δεν αποτελεί πλήρη μεταφορά όλων των χαρακτηριστικών της online έκδοσης: δεν προστέθηκε αποστολή email μέσω Resend ούτε εναλλακτικός cloud πάροχος. Η παραγωγή γίνεται αποκλειστικά μέσω του ρυθμισμένου LM Studio.

Οι ενεργές συνεδρίες είναι στη μνήμη: μετά από επανεκκίνηση παραμένουν τα αποθηκευμένα JSON για προβολή, αλλά δεν συνεχίζεται ο παλιός διάλογος. Η διάρκεια ελέγχεται από το frontend. Τρέξε έναν server process, χωρίς πολλαπλούς workers.
